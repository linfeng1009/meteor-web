# Web 镜头交互适配

本改动是为浏览器可玩性增加的宿主交互，不宣称已从EXE恢复原版镜头算法。

- 锁定后相机方位以`1-exp(-3*dt)`向敌人→玩家方向跟随。注视点向敌人胸口偏移25%，最多3 world单位；注视偏移也经过原场景射线裁剪。
- 鼠标拖动保持自由视角2秒，之后恢复平滑跟随；暂停时不改变自动方位。
- 原硬性1.8最小镜头距离被移除：在原地图/动态物体三角命中前留0.35余量；若墙更近，保留安全的更短距离，避免最小值把相机推过墙。
- 插值后重新检查实际镜头位置。镜头距玩家眼位小于2.1时仅隐藏玩家root渲染，骨架更新、命中和移动保持运行；拉远恢复渲染。
- HUD `enemy.distance`为Three世界坐标的3D距离，`enemy.bearing`为基于实际相机水平朝向的弧度，正值右、负值左。当前不新增边缘箭头。

Evidence：`tests/native-camera.test.mjs`四项回归验证锁定目标进入视野、手动覆盖/暂停、近墙不穿三角且仅改变渲染可见性、距离和方位数据。复现：

```sh
node --test tests/native-camera.test.mjs
```

浏览器人工首关是否完成由lead另行记录，本文件仅证明上述宿主交互行为。

原 5 个材质槽：0/1/4 为身体 alpha 贴图，2/3 为脸贴图；3/4 为双面，其余单面。运行时 `alphaTest=.35`。纹理存在轻微超界（身体 slot 0 的 U 最大 1.002，slot 1 的 V 最大 1.001），应保留原 clamp 行为，改变 wrap 会让边缘产生采样线。各槽共享/重复 UV 很多，不能自动 atlas 重排后继续用旧贴图。

原贴图已经烘入衣褶、皮肤亮暗与装饰线条。直接以强对比灰度生成法线，会把原阴影刻成凹槽；面部像素重影、眉眼、鼻影尤其明显。若未进行语义重绘和人工雕刻，应把本版称为“高清改良试版”，记录自动修整、细分与材质增强的方法，避免把分辨率增长描述为完整手工角色重制。

## 平滑与蒙皮风险

`normal-seam-audit.json` 模拟当前 Three `computeVertexNormals` 的面积加权法线：339 个同位点组中，329 组最大夹角大于 5°、153 组大于 60°、32 组大于 120°，最大 156.25°。这些包含锐边、重叠片和服装分层，不能据此把所有法线强制平均。

应避免以下做法：

- 各 UV 岛或材质槽单独做 Catmull-Clark/Laplacian：会在身体、颈口或袖口产生几何缝隙。
- 不加约束地 Merge by Distance：会把有意重合的发片、衣层或锐边焊成一个壳，3 条非流形边是现成警讯。
- 对全身统一强平滑：容易缩小鼻梁、眼窝、唇线、领口、手指和靴边；面数变多也可能更糊。
- 给透明片加厚、细分或三角平滑而忽略 UV/alpha：会改变头发/衣摆轮廓或露出黑边。材质 3 使用脸图且是双面，不能仅凭材质名把它认作皮肤。
- 重新自动绑定/重排骨骼：会失去原 30 骨、6 dummy 与动画的索引约定。原 dummy 还含每帧 parent 变化，武器挂点不能只保留静态坐标。
- Blender 开启 Preserve Volume 后，假定 Three 的线性蒙皮会完全一致：编辑预览与最终 Web 蒙皮必须用同一方式比较。
- 为了弥补模型位移而移动相机/碰撞体：应沿用已修复的 in-place `d_base` 规则，骨骼局部运动与角色物理根分开。

建议几何处理保留面角 UV 与材质槽，只对连通且允许平滑的面片统一位移；锐边、薄片、服装开口作保护边。新点权重从原表面重心插值或细分插值得到，并归一化到 1；若导出超过 4 个影响，显式裁剪并报告误差，不能静默丢失。

## 同镜头同动作验收

对照应同步同一角色数据、原 `source/frame`、根位置/朝向、相机投影/距离、环境光/主光、曝光、背景与渲染尺寸。原版/HD 只替换几何、贴图和材质，不得同时改变镜头距离让某一侧占更多像素。并排可采用相同裁剪后拼接，不应让两个对象共享一个存在透视尺寸差的镜头。

必要视图：全身正面、3/4、背面，脸部正面和 3/4；每张保留原版/HD 明确标签。脸近景是五官、发际和颈口的检查图，全身图是轮廓、衣纹与手持关系的检查图。把“分辨率/面数”作为规格，不能代替视觉通过条件。

| 检查项 | 通过条件 |
|---|---|
| 辨识度 | 原脸型、发型、绿色服装、饰边和体型可辨认；眼睛和眉毛位置不漂移；不可只把人物磨圆 |
| 轮廓 | 近景头颅、脸颊、肩、袖口和靴边减少明显折线；鼻梁、唇线、领口等锐形仍保留 |
| UV | 脸上不新增跨岛错位/镜像五官；颈口、身体中线、袖口无新空洞或连续纹理断裂 |
| alpha | 发片、衣摆细部保留；旋转至背面没有因单双面设置消失；浅/深背景均无明显黑边 |
| 材质 | 皮肤、织物、金属饰边可区分；织物高光不塑料，法线没有把脸部阴影刻成沟；albedo 用 sRGB，normal/roughness 用线性 |
| 尺寸 | 未改变骨骼、根位置、身高与相机跟随参考；非人为重塑区域保持原尺寸 |
| 绑定 | 全程30骨/6 dummy，挂点同帧矩阵与原版一致（浮点容差）；手指/手掌与武器握持不新增明显穿插 |
| 动作 | idle/run/jump/guard/attack/hit/death 均检查首/中/尾与剧烈折叠帧；肩肘、腰胯、裙摆无爆点/新裂缝 |
| 跳跃 | 沿用物理根与 in-place 规则，起跳/空中/落地保持人物在镜头内；HD 模型不能重新引入 d_base 双位移 |
| 性能 | 记录同场景、同尺寸的帧时间/内存变化；单角色展示顺畅，切换不会叠加未释放几何、材质或纹理 |
| 可追溯性 | 原版目录哈希不变；提供 `.blend`、生成脚本、参数与运行时资产；声明仍需人工雕刻/重绘的部分 |

自动验证重点：同一骨骼与 dummy 矩阵、权重总和、finite 顶点/法线、材质槽与UV范围、原资源哈希，以及实际帧的可见包围盒。HD 轮廓允许合理改动，不能通过强制包围盒完全相同阻止必要雕刻；也不应只测试三角面确实增加。

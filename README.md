# 流星蝴蝶剑.net Web 原版移植

基于用户本地 `lxhdj_` 客户端的浏览器移植，直接读取原版地图、人物、骨骼、动作、武器、配乐和任务脚本。Windows EXE 使用 Ghidra 离线反编译，已核实的气血、伤害和怒气公式已移入 JavaScript。

当前本地版本提供原版场景演武和钟乳洞第一关的脚本适配，已接通七星基础投射、原动作释放和实际飞行命中。本轮修复跳跃时人物与镜头分离的问题，并接入钟乳洞原肉包拾取：靠近已激活的肉包按 F 或点击提示，可恢复原 RES 规定的 300 气血并夹取到上限。首关的原路径步行、自然死亡与重开，以及隔离反击条件下的三 NPC 胜利链已通过验收；**完整活 AI 对战通关尚未证明**。完整剧情、全部兵器行为、原 EXE 的完整 AI / 物理 / 特效与多人联网尚未全部移植。

## 启动游戏

macOS 可双击项目中的「启动游戏.command」启动。需要 Node.js 20+ 和支持 WebGL 的现代浏览器。Three.js 与运行素材随项目保存，无需安装 npm 依赖。

```sh
npm run dev
```

打开 [http://localhost:4173](http://localhost:4173)。点击「执剑入江湖」进入演武，点击「原版单机」进入钟乳洞任务。「更多原版战场」可选择其他原图，「江湖人物」可选择 20 位角色。

不能双击 HTML 启动；模块、二进制和任务脚本需要 HTTP 服务。端口占用时可使用 `PORT=4174 npm run dev`。服务只监听本机 `127.0.0.1`。

| 操作 | 按键 / 鼠标 |
| --- | --- |
| 移动 | W / A / S / D 或方向键 |
| 视角 | 拖动鼠标，滚轮调整距离 |

| 锁定 / 解除 | Q |
| 切换随身兵器 | E |

## 仍有差异的系统

- 宿主移动、胶囊碰撞、镜头避障和 AI 感知在浏览器重新实现，尚未逐指令复现原 EXE。跳跃的就地播放恢复各人物原 BNC 的场景基点，保留骨骼局部姿态与武器挂点；镜头竖直跟随实际碰撞体，水平方向保留平滑。
- 肉包的 F / 触屏显式拾取、水平 1.8 / 垂直 2 世界单位范围、满血不消耗与每实例每局只消费一次均为 Web 适配；原拾取半径、满血消费和重生计时尚未恢复。其他物品效果与兵器拾取仍待实现。
- 基本出招与动作连接读取原文件；部分方向指令由资源站动作表交叉核对，EXE 完整输入识别器仍待恢复。特技怒气扣除与全部特效仍待核实。
- 七星基础投射使用原 W3_0 模型、POS200/202 释放窗口和 RES/EXE 伤害算式；飞行速度、半径、寿命、重力、瞄准与胶囊接触体是公开标注的浏览器适配。八方手里剑、怒招和完整 EF 轨迹仍待恢复，不能称为原弹道系统完整复现。
- 原脚本的少数拼写差异通过显式兼容映射处理，源脚本不改写。对白显示时长为浏览器阅读辅助。
- 第一关没有显式 `GameOver` 调用；「敌对任务 NPC 全部击败后完成」是 Rule 10 宿主适配规则，尚未从 EXE 证明。宿主记录推断与未支持 API。
- sn22 几何异常；武器 w6_5 在源目录中缺失，3 张 advancedninja 场景贴图也缺失，不用程序模型冒充原素材。
- 目前是浏览器单机，没有多人房间、网络同步或原协议兼容服务。

## 验证和追溯

```sh
npm test
npm run check
```

2026-10-26 最终本地快照：**83/83 测试通过**（26.87 秒），11 个运行模块语法检查与 `git diff --check` 通过。完整原始输出保存在 [当前全套 TAP](work/meteor-original/evidence/native-runtime-current.tap)。其中包括 10 项真实资源跳跃 / 镜头回归、9 项肉包 / 引擎拾取验收、13 项基础投射与 7 项首关 CPU 验收。此前 58/58 是历史快照，已由本次全套结果更新。

跳跃回归覆盖平地、锁定、前进、近墙及自然落地，并保留原骨盆姿态、武器挂点和非就地播放。机关伤害默认接入已完成；独立真实几何验收中，11 发各 49 伤害击中原 D_St20 石块，使其 500 HP 降至 -39，随后执行原破碎、隐藏、关闭碰撞及 D_itSt20 掉落激活。该掉落为 Item02，当前不支持拾取；肉包验收使用真实 Item01 的另一处石块掉落链，不能混称为同一物品。

首关胜利链测试冻结 NPC 反击，使用正常匕首攻击耗尽原 4000 HP，检查三次击杀、原死亡对白和唯一 Rule10 推断胜利；它不证明完整活 AI 实战通关。浏览器检查也不等同于全剧情、GPU / 触屏或线上登录后的完整验收。详见[跳跃证据](work/meteor-original/evidence/E-jump-follow-2026-10-26.md)、[肉包证据](work/meteor-original/evidence/E-native-items-2026-10-26.md)、[机关几何验收](work/meteor-original/evidence/scene-machine-audit-2026-10-26.json)、[首关验收证据](work/meteor-original/evidence/E-mission-cpu-acceptance.md)、[投射证据](work/meteor-original/evidence/E-native-projectiles.md)和[当前验证快照](work/meteor-original/evidence/E-validation-current.json)。

## 编辑与复现

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup --python scripts/blender/build_emilia_pmx.py
npm test
npm run check
```

四段Blender动作保留骨骼局部姿态；游戏跳跃世界位移与镜头由Web宿主控制。运行模型沿用原p0骨架与挂点，剧情仍为原角色身份。

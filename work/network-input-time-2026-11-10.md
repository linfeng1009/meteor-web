# 保留客人按键节奏

本轮按game-improvement-plan-2026-11-10.md实施，最终提交PR供维护者合并，不执行主分支合并。

问题：同一HTTP批次内的按下/松开/再次按下此前都用同一个房主elapsed，导致站姿闪避和蹲姿翻滚要求的正时间间隔无法满足。客户端现在在采集操作及look时记录performance单调时钟秒数，原批次重试不更新时间。中继保留时间字段，按序号去重，并在完整校验后拒绝非法、超界或倒退时间，不部分写入队列。

房主每名远端玩家维护指令识别时间，方向缓冲、双击和攻击指令使用该时间；世界elapsed、固定逻辑步、位置、碰撞、伤害和受击恢复输入的到期时间仍由房主推进。缺少时间的旧客户端使用原房主时钟兼容路径，需双方刷新才获得同批次节奏修复。不提供预测、回滚或迟到输入的世界状态回放。

新增验证：原资源CPU战斗中，单批次快速双击可触发165站姿闪避、177蹲姿翻滚和277忌冬雨，房主世界时间与角色位置没有按客户端时间快进；受击恢复指令仍在房主0.3秒后过期。还覆盖重试原时间保持、时间非法/倒退批次原子拒绝及重复批次去重。

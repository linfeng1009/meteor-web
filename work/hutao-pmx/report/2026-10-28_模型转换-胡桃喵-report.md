## 编辑与复现

运行项目的 `启动游戏.command`，进入「人物工坊」，选择「YS-胡桃 · 模型适配」，点击「使用此外观进入游戏」。

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup --python scripts/blender/build_hutao_pmx.py
npm test
npm run check
```

Blender 5.4.0 Alpha，源文件 `work/hutao-pmx-model/胡桃喵-完整模型-流星动作适配.blend`。四段Action分别为6待机、144跑步、151跳跃局部姿势、262持剑攻击；世界跳跃由Web宿主处理。所有输入下载文件保持只读。

## 实际边界

这是首版动作适配。未实现MMD刚体、头发衣摆物理、面部morph、完整手指或原神着色和技能。大幅动作时短裤/上腿仍有局部形变：最差极短边约16.5mm变80.6mm，最大比4.88；不能称零拉伸或零穿模。长发/衣摆仍可能穿插，后续可在同一.blend内继续精修蒙皮与物理。

Cycles脸部物理光照有小型三角明暗边界；独立法线/UV检查与纯发光贴图对照确认原脸面完整，Web预览不复现同样黑块。没有删面或涂抹贴图掩盖。

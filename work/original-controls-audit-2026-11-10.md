# 原版 PC 操作审核（2026-11-10）

审核对象：2002 年《流星蝴蝶剑.NET》PC 操作，不采用后来 Online、手机游戏或模拟器映射。开发位置为 `feature/自定义按键`，4174 预览；4173 的目录与进程均未修改。

## 证据与限制

- [流星蝴蝶剑.NET 基本操作资料](https://wiki2.gamer.com.tw/wiki.php?f=M&n=4516%3A%E5%9F%BA%E6%9C%AC%E6%93%8D%E4%BD%9C&ss=4516)：明确区分自由镜头与战斗锁定镜头，以及基本键位、组合移动和其他功能键。它是社区资料，不能当作已验证的原版可执行程序行为。
- 本仓库 `work/meteor-original/README.md` 与 `report/2026-10-26_逆向-跳跃对齐与肉包交互-report.md` 明确将显式拾取、部分输入和镜头列为 Web 适配；`report/2026-11-06_逆向-十二兵器与群战输入-report.md` 说明未锁定攻击应保留人物朝向。
- 当前仓库没有原版默认按键配置或完整操作说明书，也未在本机运行原版客户端逐帧对照。此次是操作层代码审核及可确认差异修正，不是完整原版复刻验收。

## 本轮修正

| 项目 | 发现 | 处理 |
| --- | --- | --- |
| 默认键位 | J/K/L/C 和箭头别名是网页布局 | 默认改为 WASD、鼠标左键攻击、右键跳跃、Space 防御、Ctrl 蹲下；Q 锁定与 E 换武器保留 |
| 自定义鼠标 | 鼠标左右键硬编码，设置只改键盘 | 鼠标左/中/右键进入同一绑定表，可设置、保存与恢复默认 |
| Ctrl 蹲姿移动 | 原键盘过滤器拒绝所有 Ctrl 组合 | 绑定 Ctrl 时允许 Ctrl 与移动键共同输入，松开、暂停或失焦释放动作 |
| 自由镜头 | 旧服务需按住拖动；此前开发版已加入 Pointer Lock | 保留锁定光标后的直接鼠标转向，自由状态人物朝向跟随镜头；浏览器拒绝锁定时提示点击重试 |
| 战斗镜头 | 鼠标可临时覆盖 Q 锁定镜头两秒 | 有效目标锁定时拒绝鼠标转向、拖动与滚轮调整，目标跟踪不再受自由镜头计时器影响；目标死亡或解除后恢复自由转向 |
| 鼠标释放 | 右键抬起会错误取消防御 | 改成释放对应绑定动作；暂停、失锁和更改绑定时清除按住状态 |
| 引导与旧设置 | 提示残留 J/K/L 等默认；旧默认已存入浏览器 | 提示改读绑定表；未修改过的旧网页默认自动迁移，用户自定义布局保留；恢复默认切回原版基础布局 |

锁定战斗镜头目前仍使用项目既有目标跟踪与避障算法，并未证明其角度、速度、构图与原版逐帧一致。自由朝向与移动的适配同样需要普通浏览器实机验收。

## 验证

新增覆盖默认键位、Ctrl 蹲姿移动、可重绑鼠标、动作释放、自由/锁定镜头互斥与旧默认迁移；原跳跃和镜头测试回归。最终全套 429 项：424 通过，5 项失败均为原仓库缺少豆包 / 春田源归档的既有问题；39 个运行模块语法检查通过。旧测试中允许鼠标暂时覆盖战斗锁定的断言已按本轮模式修正更新。

浏览器确认默认布局迁移、鼠标中键录入、恢复并保存原版基础布局；截图为 `work/original-controls-settings.png`。后续仅调整了动态引导文案，并再次通过语法检查。

此前自动化浏览器未授予 Pointer Lock；不能以该环境证明鼠标手感和原版完全一致。4174 可供普通 Chrome / Edge 实机验收，4173 持续保留原版本。

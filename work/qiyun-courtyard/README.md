# 栖云古庭

2026-11-10 制作的山间遗迹战场首版。首页战场列表第一项选择「栖云古庭」，点击「执剑入江湖」进入演武。

Blender 中制作了石板庭院、铜纹嵌线、山门、后殿、侧亭、树木、花草、岩壁与远山。Three.js 补充天空、山雾、水面波纹、瀑布流动、树叶摆动和飘落叶片。地面、边栏、台阶、屋顶和门柱使用独立碰撞网格；石板缝隙不参与脚部碰撞。

## 文件

- `栖云古庭.blend`：可编辑工程，贴图已打包。
- `栖云古庭.glb`：静态几何、颜色和材质交换文件。动态水面、风、天空与雾由运行时实现。
- `overview-0001.png`：Blender 场景总览；游戏画面见实战截图。
- `../../dist/assets/enhanced/maps/qiyun/`：随游戏分发的几何二进制、材质清单、石材贴图和地图缩略图。
- `../../dist/qiyun-courtyard.js`：资源读取、材质、天空、水面和风。
- `stone-texture-prompt.txt`：内置 image_gen 的最终石材提示词。生成结果复制为运行目录内的 `limestone.png`，运行不依赖工作区外的文件。

静态场景按材质合为 16 个可见网格，另有天空和一批实例化落叶。可行走区域与小地图使用局部战场边界，远山只参与视觉。精致画面使用一盏 2048 阴影太阳；流畅优先关闭新地图实时阴影。

## 重新制作

在项目根目录运行：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --python scripts/blender/build_qiyun_courtyard.py
```

脚本确定性生成模型，并导出运行几何、Blender 和 GLB。运行几何的坐标为米、Y 轴朝上。

## 检查

`validation.tap` 包含新地图碰撞、穿过庭院与山门、攀登后殿台阶、侧亭地面、光照恢复、资源释放，以及原地图生命周期、跳跃镜头和兵器技能的检查。浏览器验证首页选择、实战交战、跳跃、技能与新旧地图切换。控制台未发现新地图着色器错误。

这是可玩的美术样板，建筑、植被和岩石为程序建模；还可继续做美术雕刻、专用材质和局部装饰细化。未进行低端移动设备帧率验收。

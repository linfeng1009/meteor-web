# 冷墨江湖界面落地

## 视觉与动线

- 墨黑、骨白、朱砂与旧铜；静态山月与刀剑构图，无外部字体下载、菜单粒子或全屏模糊。
- 首页只负责选择联机、单机、演武；主导航固定，资源鸣谢与人物工坊位于页尾。
- 演武整装集中人物、外观、地图、兵器；地图可搜索，练习选项折叠，入场按钮位于粘性底栏。
- 联机大厅独立成页，列表与创建 / 房间号加入分区；支持按盟主 / 死斗筛选，刷新保留表单草稿。
- 房间显示玩家席位、队伍、准备状态、邀请与尚未满足的开局条件；沿用现有固定地图及装备限制。
- 单机先选关卡，查看目标与任务装备，再确认进入。
- 设置分画面、声音、操作与键位、界面与提示；键位按移动、战斗、锁定与兵器分组，保留保存与恢复默认。
- 暂停提供继续、招式、设置、重新整装和退出；联机明确不暂停其他玩家。
- HUD 收起完整键位表，气血怒气在左上、目标与时间在上中、兵器在左下；联机中央计时改为剩余时间，比分移至小地图下方。
- 新浏览器默认关闭帧率显示，保留已保存的个人开关。

## 性能边界

菜单使用静态 DOM / CSS。`menuIdle` 在菜单阶段跳过世界更新、镜头更新与 WebGL 绘制，持续清除时钟累计量，返回战斗时复位帧率统计。战斗仍使用原固定逻辑步长、渲染流程和自适应倍率；未新增战斗特效或动画循环。

新增引擎回归测试验证：60 次菜单帧不进行世界、表现、镜头或绘制调用，恢复战斗时只前进当帧应有的一步。

自动浏览器中的帧率实验出现约 1 FPS 的固定节奏，实验页判为 `validForComparison=false`、`possibleThrottling=true`。此结果不作为真实流畅度验收或帧率承诺。尝试切到原生 Chrome 前台时，电脑使用工具因无法可靠识别当前网址而中止，之后没有继续界面操作；真实前台鼠标锁定后的流畅度仍需复测。

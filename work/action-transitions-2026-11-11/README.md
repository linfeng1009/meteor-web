## 本轮修复

### 起跳、空中、下落与落地

原代码在起跳后强制重播并循环152/154/156/158，阻断了POS原有的后续链接；无跳跃的离地跌落也套用152。

现在允许原控制器按POS完成151→152→180、153→154→180、155→156→180、157→158→180，保留原混合过渡，不重启短暂空中动作。180进入时即采用POS一帧循环，直到实际碰撞落地。边缘跌落直接进入180；落地继续现有武器待机/移动选择。空中攻击和受击具有原有优先级，不被下落显示强制覆盖。

依据：本地P0.POS链接；`work/meteor-original/evidence/hit-reaction-getup-2026-10-30/004cf7d0_FUN_004cf7d0.c`对152/154/156/158/180的保留分支；`dist/native-combat.js`已有POS链接/混合处理。20名原角色的链接、方向移动动作和180保持帧均已逐一读取核对，详见catalog-inventory.json。

### 面向镜头的地面移动

原代码在面向镜头/锁定目标时，向右、向左、向后移动仍统一播放向前跑144，形成前进动作横滑/倒滑。现在前进保留144，横向/后退使用141/142/143；减速时继续当前动作，停下恢复待机。没有固定朝向、会转身朝移动方向跑的模式沿原逻辑执行。蹲走145–148保持上轮修复。角色移动速度和加速度未在本轮改动，动画与原版速度、脚掌接触的精确配合仍是待核实事项。

依据：本地POS对应帧、`004cc730_FUN_004cc730.c`对140/144及141/142/143的原方向映射；方向名称可交叉参考此前记录的动作表。选方向仍通过当前Web输入适配，不能据此宣称完整原键盘采样已恢复。

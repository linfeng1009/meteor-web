# 流星蝴蝶剑.net Web 原版移植

基于用户本地 `lxhdj_` 客户端的浏览器移植，直接读取原版地图、人物、骨骼、动作、武器、配乐和任务脚本。Windows EXE 使用 Ghidra 离线反编译，已核实的气血、伤害和怒气公式已移入 JavaScript。

当前本地 **v0.7.6** 提供五项原版任务：钟乳洞、炎硫岛、炽雪城、决死阵和飞鹏堡。炽雪城使用原地图、七名 NPC、落雪参数与城门脚本，击破敌城门后播放原坍塌动画并结算。决死阵保留100块地板分圈塌落、双方尸毒与存活结局；飞鹏堡保留七名初始敌人、萧安逃跑路线及条件援军无名。

乾坤刀「死斗」末击现在按原EF时序播完六组交错刀光，修正动作提前结束时删掉后半段特效的问题。原POS的Drag窗口、颜色和武器DES端点接入柔边拖尾，适用于有原拖尾定义的挥砍与技能；怒招光效适度提亮。特效仅改变显示，伤害、扣怒和动作时序仍由原战斗系统决定。

起跳段现在从各人物原 AMB 的 `d_base` 场景轨迹移动碰撞体，原皮肤保持就地播放，镜头仍跟随同一位置。由此可以登上决死阵约4.68米高的中央石台；NPC 路径适配器也可请求原起跳动作。中断、下落、碰撞和 AI 决策仍有 Web 适配，并非完整原物理。

首页、兵器选择和招式表已列出全部十二类兵器：长剑、大刀、长枪、匕首、飞镖、双刺、重锤、火铳、飞轮、乾坤刀、指虎、忍刀。目录共196条指令，179条有原动作及近身、投射、效果攻击或架式转换入口，17条缺少必要效果而禁用；可执行入口不等于完整技能效果已还原。乾坤刀区分持刀、持枪、拔刀三式，火铳可射击，飞轮可投出并等待回收。

重锤、火铳、飞轮、指虎与乾坤刀新增接通10项怒招，包括金钟罩、俯爆压头灯、炎狱、焚雷、千刀万刮、万劫千秋、夺命轮盘、虎啸波、饿虎嗜血和勾魂锁。使用原攻击窗口、特效攻击盒及收招链；金钟增加20防御120秒，嗜血增加40攻击90秒，重复施展刷新时长。乾坤刀举刀时跟随原手部辅助点；↓↓A收刀时按原POS阶段将刀身送入刀鞘，刀尖对齐原DES鞘端，刀柄留在鞘口，拔刀攻击后再回鞘。原模型、贴图与控制轨道保留；收鞘插值和状态触发有明确Web适配，完整原物理、粒子和全部状态条件仍未完成。

演武敌人现在先经过发现判定，再转向、追击和攻击。演武与单机共用原View距离、远处前方判定、近处周围感知和遮挡检查，并保留原短距离目标记忆；重生清空旧目标。单机待机/巡逻敌人发现玩家后可追击，剧情明确下达的追击、报告与增援命令继续执行。原四方阵正常开局的CPU检查中，一名敌人发现并靠近玩家，另外两名保持未发现状态；完整原AI的权重、随机环顾和战术时序仍待恢复。

地面/空中八方绝已接原十二攻击球及命中减20怒；落樱雪使用原多段动作、特效攻击和蛊毒；赤练牙附加原七星毒。持续效果改用原0.2秒专用更新及计数/到期顺序，重复命中刷新时长。特效独立位置/旋转绑定也已修复。粒子表现、全部附加状态和精确联网时序仍未完成。

原ACT的招式组现已参与连招选择：剑第三式可以直接接凤凰羽后段，长枪第三式可以接万圣龙王破的冲击段，部分刀招也能接腥风的原中间段。按前招允许列表中的原顺序选择成员，保留排队时机，并在实际起手时支付一次怒气；同组不等于任意互连。匕首「阎罗」恢复原突进、狭窄效果攻击盒、109受击动作和349收招。

受击期间按住防御，恢复时会立即接上护架，不再依赖重新按键或系统键盘重复事件；恢复前0.3秒内的一次攻击输入可保留到硬直结束，长时间倒地会使其过期。未锁定时近战保持玩家面向，Q 锁定才自动朝向目标。普通命中仍可打断招式，原版霸体例外、爆气解围和完整群战 AI 节奏尚未核实。

长枪「万圣龙王破」的气罩与前方冲击体现在能实际命中，并沿原受击轨迹击退、倒地和起身。特效碰撞读取原EF球、柱、盒的攻击包围盒、动画键与父绑定，和普通兵器共用原伤害/反应链，同一攻击窗不因多个特效节点或逐帧采样重复扣血。EF秒时钟与POS播放速度分开，修正原底端展开的冲击柱被画成居中展开的问题。原人物精确接触体、其他EF类型及全部技能效果仍未完成。

出招、起手、收招和受击位移读取原 `d_base` 场景轨迹。`TargetMove` 是原轨迹倍率，`TargetValue` 控制受击动画的最低保持时长，均按原消息的百分位打包方式接入。已修复单帧空中姿态采到相邻帧而悬空、已排队续招在落地时丢失的问题；方向受击、各兵器防御反应与过渡也已接入。原物理、完整输入识别和全部技能效果仍有差异。

CPU 验收以正常移动、跳跃与防御，从原出生点完成决死阵约199秒的存活流程，冷燕 AI 和所有塌落地板均启用，未直接改血量或结算。飞鹏堡验证了原7500HP萧安的实际受击胜利链、实际逃跑失败、条件援军与重开；其胜利测试冻结 NPC 反击，不代表完整活 AI 战斗通关。本轮浏览器试玩受工具访问限制未完成，线上版本未更新。

## 启动游戏

首页战场列表新增「栖云古庭」：Blender 制作的山间庭院演武地图，带石材地面、山门、侧亭、古树、瀑布、动态水面和山雾。选择该地图后点击「执剑入江湖」。精致画面启用实时阴影，流畅优先关闭新地图阴影。可编辑工程、GLB 与制作记录位于 `work/qiyun-courtyard/`。

macOS 可双击项目中的「启动游戏.command」启动。需要 Node.js 20+ 和支持 WebGL 的现代浏览器。Three.js 与运行素材随项目保存，无需安装 npm 依赖。

```sh
npm run dev
```

打开 [http://localhost:4173](http://localhost:4173)。点击「执剑入江湖」进入演武，点击「原版单机」选择五项任务。「更多原版战场」可选择其他原图，「江湖人物」可选择 20 位角色。

不能双击 HTML 启动；模块、二进制和任务脚本需要 HTTP 服务。端口占用时可使用 `PORT=4174 npm run dev`。服务只监听本机 `127.0.0.1`。

## 局域网联机

世界逻辑采用固定60Hz更新，场景脚本、战斗、运动、碰撞和投射物使用同一步长；镜头与视觉效果独立按渲染帧更新。短暂卡顿会补算，每帧最多15步（250毫秒），更长的挂起时间会丢弃；暂停和恢复清空未完成步长，不补算暂停时间。此为网页工程基准，不代表已核实原版逻辑频率。房主长期后台运行仍受浏览器限制，尚未接入独立战斗服务器或本地角色渲染插值。

统一通过 `npm start` 或 `npm run dev` 启动，默认4173端口，同时提供游戏页面和联机房间API。可通过HOST/LAN_HOST/PORT指定监听地址。当前只保留4173开发服务，直接运行本开发工作区，不再区分稳定版和预览版。

同一局域网双方打开同一4173地址，点击「联机对战」：一方创建房间，将六位房间号告知另一方；另一方加入。双方准备后由房主开局，两端载入完成才开始战斗。首版固定四方阵、孟星魂基础模型与长剑，关闭无限怒气，支持移动、跳跃、蹲下、防御、翻滚、招式、受击、死亡重生和战绩同步；换兵器与道具拾取在此模式中禁用。

房主浏览器统一运行现有原数据战斗逻辑，加入者只提交操作并显示状态，不自行决定伤害/HP。该版本使用约70毫秒轮询的Web房间协议，不兼容原版客户端网络协议。房主需保持前台运行；后台节流、延迟预测/补偿、断线重连、房主迁移、更多人数、原版完整玩法与胜负条件仍待完善。菜单不会暂停网络战斗，离开会结束本局。

双方通过独立控制状态保存按键、方向缓冲、翻滚双击、受击后排队出招和锁定目标，共用角色输入与更新入口。远端更新不再临时替换本地角色、敌人列表、出生点或镜头引用；受击与重生只清理对应玩家的指令。当前仍固定双人，尚未完成独立服务器战斗核心。

联机菜单和窗口失焦会释放本地按键及排队指令，并向房主发送可重试的释放操作；菜单期间拒绝新的本地战斗输入，对方继续行动。客人按Q只在按下时切换本地锁定，松键不会再次切换。

联机协议第2版按对局编号和操作序号确认：客人重试未收到确认的批次，中继保留操作直到房主执行后确认，房主跳过重复投递。连续输入分批发送，队列超限、连续3次请求失败或执行错误会明确结束会话，不会悄悄丢掉攻击后继续。确认状态只保存在本次会话内，不支持浏览器刷新或服务重启后的续局。升级此协议需要重启服务，双方刷新页面并重新创建房间。

## 打包本地游戏

执行 `npm run package`（打包时需要 Python 3），生成 `artifacts/meteor-web-v<版本>.zip`。压缩包包含整个 `dist/`、本地服务器和启动文件，YS-胡桃、YS-影、RE0-爱蜜莉雅、豆包、春田的转换网格和原贴图会一同打入。打包不依赖 Git 是否暂存这些资源。

打包后自动校验包内文件哈希、模块导入和五个导入人物的网格/贴图引用，并生成 `.verification.json` 与 `.zip.sha256`。完整解压后可双击「启动游戏.command」或运行 `npm start`。游戏运行无需原始 PMX、Blender 或 Downloads 目录；角色运行资源已保存在项目内的 `dist/assets/enhanced/`。

## 操作

桌面浏览器点击进入或继续对战时会请求锁定鼠标：自由镜头下直接移动鼠标即可转动视角，无需按住拖动；Q 锁定目标后镜头由目标控制，不接受鼠标转向，再按 Q 解除。左键攻击、右键跳跃，Esc 暂停并释放鼠标；返回首页或切换窗口也会释放。若浏览器拒绝首次锁定，可点击游戏画面重试，这次点击只锁定，不触发攻击。触屏仍使用原来的拖动与触屏按钮。

首页「游戏设置 → 设置按键」或游戏暂停菜单「自定义按键」可更改键盘操作。点击键位后按下新按键，每个动作最多两个键，重复键会提示冲突；Esc 固定为暂停，也用于取消按键录入。点击「保存键位」后生效，刷新页面仍会保留；「恢复默认」会立即恢复并保存默认键位。关闭面板会丢弃尚未保存的修改。默认采用原版 PC 的 WASD、鼠标左键攻击、鼠标右键跳跃、Space 防御、Ctrl 蹲下、Q 锁定、E 换武器。此前保存过网页快捷键的浏览器可点击「恢复默认」切回这套布局。

键位保存在当前浏览器的当前网站地址下，其他设备、端口或 localhost / 局域网 IP 不共用设置。浏览器禁用存储时会提示保存失败。鼠标左右键也可重新绑定；触屏按钮保留原动作，招式表及战斗提示显示当前键位。

| 操作 | 按键 / 鼠标 |
| --- | --- |
| 移动 | W / A / S / D 或方向键 |
| 视角 | 自由镜头下直接移动鼠标；Q 锁定后鼠标不再转动镜头 |
| 出招 | 鼠标左键；按原 ACT 允许的连接连续出招 |
| 防御 | 按住 Space |
| 跳跃 | 鼠标右键 |
| 蹲下 | 按住 Ctrl |
| 锁定 / 解除 | Q |
| 切换兵器 | E；演武循环十二类，剧情只切换原随身两件 |
| 拾取附近已接入道具（单机） | F 或点击拾取提示 |
| 演武兵器选择 | 首页或暂停后的兵器选项可选十二类；1–5 保留剑 / 刀 / 枪 / 匕首 / 飞镖快捷键 |
| 暂停 | Esc 或右上角暂停按钮 |

按住蹲下键（默认 Ctrl），快速按两次同一方向键、两次之间松开，可触发前/后/左/右翻滚。使用原176–179号动作及动画位移，受现有碰撞与受击系统约束。站姿双击同一方向已接通长剑、长枪、大刀、飞镖、火铳、飞轮、乾坤刀与指虎的原兵器四向闪避动作，可接攻击，并保留方向指令供招式识别；匕首、双刺、重锤与忍刀的站姿映射暂未接入。双击识别窗口0.3秒仍是网页适配，原客户端的完整输入时序尚未复核。

地面道具已接通普通/大/小肉包、毒肉包、华陀、铜皮、嗜战、猫足、气元及已验证的圣诞蛋糕、元气糖、围巾、手套、长靴，共14种。按实际DES模型匹配原RES记录，不按显示名称猜效果；不凭空生成地图没有的物品。成功后禁用同一实例、执行实际存在的OnPickUp回调，应用属性/持续效果并刷新HUD。即时回血/回怒道具在资源已满时保留；持续增益不受满血限制，重复拾取同一道具刷新而不叠加。范围、F显式交互、满资源保留与不自动重生仍是Web适配。

拾取表现使用原GetItem.ef的平面/圆柱动画与原Get.wav音效；EF粒子和持续附身光效仍待还原。该EF绑定到网页拾取成功事件，RES数值特效索引映射尚未核实，不强制添加没有依据的角色弯腰动作。燕羽、风水、炼化及部分特殊道具和武器拾取仍未接通，未实现的物品不会被当作肉包消耗。

触屏提供方向、攻击、防御、跳跃、蹲下、换兵器和锁定，钟乳洞靠近可拾肉包时显示拾取按钮。切出页面或窗口失焦自动暂停。原声音乐和音效需通过页面按钮开启，浏览器可能限制自动播放。偏好保存在当前浏览器。

## 手搓招式

招式记号里的 **A 表示攻击，默认按鼠标左键**；键盘 A 本身是左移。↑ / ↓ / ← / → 对应 W / S / A / D。连续按顺序输入，重复方向要先松开再按。以下都是零怒普通招式：

| 兵器 | 招式 | 指令 | 键盘示例 |
| --- | --- | --- | --- |
| 大刀 | 旋风，旋身后自动收斩 | ←→A | A、D、鼠标左键 |
| 剑 | 忌冬雨，五段突刺 | ↓↑↑A | S、W、松开 W 再按 W、鼠标左键 |
| 长枪 | 蛟龙海覆波 | ←→A | A、D、鼠标左键 |
| 长枪 | 应龙空翔蹴 | ←→↑A | A、D、W、鼠标左键 |
| 匕首 / 剑 / 枪 / 刀 | 各自原版空中下击 | 跳、↓A | 鼠标右键跃起后，S、鼠标左键 |

按 Esc 暂停后选择「查看招式」，可按兵器查看地面、空中、怒气与前招衔接条件；筛选说明不会改变实际装备。长枪、大刀的空中 A 为原空踢，空中 ↓A 才是下击。匕首普通 A 链恢复为两击，↑A 是另一条独立链。飞镖没有近战下刺，不添加该指令。

乾坤刀初始为持刀式：←A 转持枪，↓↓A 收刀入鞘；持枪式用 →A 转回持刀、↓↓A 收刀入鞘。收刀后进入“拔刀式”的待发状态，→A 转持刀、←A 转持枪，↓↑A 或↑↓A拔刀攻击后自动回鞘。HUD与招式表显示架式名称；↓↓A的实际动作是收刀。转换也有原动作和连接时机，按键需要依序输入。

乾坤刀「勾魂锁」需持枪式后输入↓↑A、60怒气；「死斗」需拔刀式后输入↓↓↑A、100怒气。形态不符时显示切换提示，完整大招指令不会降为普通攻击。重锤金钟罩是↓↑↑A，指虎嗜血是↓↓↑A；火铳、飞轮的100怒招均为↓↑↑A。A仍表示攻击键（默认鼠标左键），重复方向先松开再按。

长枪大招与匕首「阎罗」输入均为 ↓↑↑A，即 S、W、松开 W 后再按 W、鼠标左键，正常需要100怒气。长枪三连后接该指令会按原ACT直接进入冲击段；匕首阎罗沿原轨迹向前突进，命中区很窄。首页已有「无限怒气 · 技能调试」开关，可用于连续试招；关闭后恢复正常门槛和扣怒，NPC不受该开关影响。

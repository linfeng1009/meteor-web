# 重设计冷墨江湖界面并整理游戏操作动线

原首页同时堆叠地图、外观、装备和多个玩法入口，复杂流程依赖弹窗，玩家下一步目标不清晰。本次以冷墨、骨白、朱砂、旧铜统一风格，并拆分首页、战前整装、联机大厅 / 房间、单机任务确认和分类设置；战斗 HUD 保留必要状态，完整键位说明收入暂停菜单。

菜单改为静态构图，并跳过后台世界更新和 WebGL 绘制，进入战斗时清除累计时间。没有增加战斗动画循环、全屏模糊或粒子效果。联机列表保留草稿并支持模式筛选，单机明确显示目标与起始装备。

验证：语法检查通过；定向回归 68 项通过；全量 624 项中 611 项通过，13 项为原有角色源资源缺失，无新增失败。实际浏览器验证双人加入、准备、开局、暂停、退出，以及设置、键位与任务确认动线；检查 1280×720 和 390×844 布局。

性能限制：自动浏览器采样受到约 1 FPS 的固定节奏影响，被实验页标记为无效对照，尚不能代替真实前台鼠标锁定测试。菜单不提交绘制及恢复无补帧已有自动测试覆盖。

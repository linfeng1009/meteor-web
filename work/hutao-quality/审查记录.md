# 胡桃 MOD 导入：独立质量审查

日期：2026-10-27。只读源目录 `HuTaoMod4K`，未执行注入器、原神程序或包内代码。源目录的全部文件大小与 SHA-256 见 [source-audit.json](source-audit.json)。

## 已核实输入

INI 明确声明 Position/Blend/Texcoord 三流 stride 为 40/32/12，Head 与 Body 的索引类型为 R32_UINT。实测三流均为 14,672 点，无不完整记录。布局按实际浮点范围、单位法线/切线与归一化权重交叉验证：

| 流 | 实测布局 | 约束 |
| --- | --- | --- |
| Position | float3 position + float3 normal + float4 tangent | 全部有限，法线/切线长度约 1，tangent.w 全部 1 |
| Blend | float4 weight + uint4 index | 权重和最大误差 1.49e-7；有效源骨编号 0..118 |
| Texcoord | 4 byte COLOR + float2 UV | UV 有限且在 0..1 内；不能从开头直接按 float2 读取 |
| Head IB | 5,503 三角面，唯一点 0..4,244 | 无越界，无重复索引退化面 |
| Body IB | 11,858 三角面，唯一点 4,245..14,671 | 无越界，无重复索引退化面 |

合计 17,361 三角面。源模型为 Y-up，范围约 x±0.416、y -0.002..1.594、z -0.283..0.178。导入 p0 的 Z-up 坐标和尺寸时需一次明确转换；轴翻转、UV 翻转和纹理上传翻转不得混为一谈。

GIMI 官方指南解释了 position/normal/tangent、blendweight/blendindices、color/texcoord 拆分及由 INI 指定替换缓冲的方式。这是格式语义的参考，不是源胡桃骨架或完整角色已存在的证明。[GIMI Usage Instructions](https://github.com/SilentNightSound/GI-Model-Importer/blob/main/Guides/UsageInstructions.md)

## 贴图与透明度

BodyDiffuse 为 4096² BC7 sRGB（DXGI99），有 13 级 mip；HeadDiffuse、FaceHeadDiffuse 为 1024² sRGB；Head/Body LightMap 是 1024² BC7 线性数据（DXGI98）。LightMap 不能直接充当普通法线图。

对原 DDS 的只读解码发现：HeadDiffuse alpha 254..255；FaceHeadDiffuse alpha 0..239 且没有任何完全不透明像素；BodyDiffuse 多数 alpha 为 0，并混有中间值。这些通道不能未经判断直接接作 Three.js 的全局透明度/裁切图，否则可能删除皮肤和脸部。见 [source-texture-alpha.json](source-texture-alpha.json)。审查 PNG 只是原 DDS 的无内容改动解码视图，不作为运行贴图。

HeadDiffuse atlas 包含帽、发和虹膜；FaceHeadDiffuse 是独立脸皮肤 atlas。INI 对 FaceHeadDiffuse 只有纹理替换，没有独立 face VB/IB 替换条目。是否缺少原生动态脸/眼几何，必须由真实网格前视图确认；不可将整个 Head IB 用一个错误贴图蒙混过关。

## 适配边界与验收

包内没有 BNC、FBX、GLB、Blend 或 PMX 骨架，也没有 rest/inverse-bind 矩阵。119 个源编号不能直接用于目标 30 骨。新增几何仅能作为新的 Web 外观重绑到 p0，不能声称原神完整骨架、表情、裙摆/头发物理或原动作已移植。

最终资产需按以下标准补验收：

- 原三角、UV 和材质岛保留；新增的缺失补件另列来源，不冒充包内原网格。
- 贴图文件真实存在且有正确色彩空间，头脸眼与 alpha 在前/侧/背实际渲染中正确。
- 每顶点目标骨索引 0..29，最多四影响，权重有限非负且归一。
- idle、run、jump、attack、guard 的实时蒙皮包围盒有限，不出现手臂/头发/裙摆整体甩飞或人物主躯干坍塌。
- 同一 p0 skeleton、bindMatrix、source/frame 与武器挂点在外观切换前后不改变；只换皮肤不改 HP、任务身份或武器。
- 试版自动权重转移的肩肘、长发与裙摆限制应如实说明。截图与普通步行实机由主代理另行记录。

# 流星蝴蝶剑.net Web 原版移植

基于用户本地 `lxhdj_` 客户端的浏览器移植，直接读取原版地图、人物、骨骼、动作、武器、配乐和任务脚本。Windows EXE 使用 Ghidra 离线反编译，已核实的气血、伤害和怒气公式已移入 JavaScript。

当前版本提供原版场景演武和钟乳洞第一关的脚本适配。完整剧情、全部兵器行为、原 EXE 的完整 AI / 物理 / 特效与多人联网尚未全部移植。解析出素材或反编译出 C 代码不等于这些系统已经在 Web 中运行。

## 启动游戏

macOS 可双击项目中的「启动游戏.command」启动。需要 Node.js 20+ 和支持 WebGL 的现代浏览器。Three.js 与运行素材随项目保存，无需安装 npm 依赖。

```sh
npm run dev
```

打开 [http://localhost:4173](http://localhost:4173)。点击「执剑入江湖」进入演武，点击「原版单机」进入钟乳洞任务。「更多原版战场」可选择其他原图，「江湖人物」可选择 20 位角色。

不能双击 HTML 启动；模块、二进制和任务脚本需要 HTTP 服务。端口占用时可使用 `PORT=4174 npm run dev`。服务只监听本机 `127.0.0.1`。

## 操作

| 操作 | 按键 / 鼠标 |
| --- | --- |
| 移动 | W / A / S / D 或方向键 |
| 视角 | 拖动鼠标，滚轮调整距离 |
| 出招 | J 或鼠标左键；按原 ACT 允许的连接连续出招 |
| 防御 | 按住 Space 或 K |
| 跳跃 | 鼠标右键或 L |
| 蹲下 | 按住 C |
| 锁定 / 解除 | Q |
| 切换随身兵器 | E |
| 演武兵器选择 | 1 剑 / 2 刀 / 3 枪 / 4 匕首 |
| 暂停 | Esc 或右上角暂停按钮 |

触屏提供方向、攻击、防御、跳跃、蹲下、换兵器和锁定。切出页面或窗口失焦自动暂停。原声音乐和音效需通过页面按钮开启，浏览器可能限制自动播放。偏好保存在当前浏览器。

## 已接入原版内容

| 系统 | 原数据与实现 | 范围 |
| --- | --- | --- |
| 地图 | GMB / DES、原 UV、顶点色、材质和贴图 | 22 份地图，21 份几何有效；sn22 非有限顶点异常，禁用并保留原因 |
| 场景物件 | DES 引用 cmodel、FMC / POS | 114 种模型记录均具备原文件（含双刺左右件别名）；包含原机关、门、活动地板模型与动画 |
| 人物 | 20 套 SKC / BNC / AMB / POS | 原模型、蒙皮、骨架、手部挂点和动作；Common 动作 17,061 帧 |
| 武器 | Meteor.res、原模型与材质 | 59 个物品记录、71 个模型；58 个物品具备模型，w6_5 源文件缺失 |
| 战斗 | POS 攻击帧与速度、ACT 连接、RES 与 EXE 数值 | 匕首、剑、枪、刀主要演武兵器；飞镖家族已解析，完整投射行为待还原 |
| 任务 | PST / H 解析器、包含解析和宿主 | 钟乳洞第一关 NPC 配置、对白、巡逻和场景回调；其他关卡待逐关验证 |
| 声音 | 原 MP3、WAV、EF 音效引用 | 菜单与对应主场景配乐、出招与碰撞声音 |

主资源、人物、场景模型与武器采用独立清单。主清单 3,036 条记录不包含其他独立清单，不能当作全部文件总数。各清单保留来源、原始文件与 SHA-256，BMP / TGA 转换另有记录。原客户端没有被修改或执行。

## 仍有差异的系统

- 宿主移动、胶囊碰撞、镜头避障和 AI 感知在浏览器重新实现，尚未逐指令复现原 EXE。
- 基本出招与动作连接读取原文件；部分方向指令由资源站动作表交叉核对，EXE 完整输入识别器仍待恢复。特技怒气扣除与全部特效仍待核实。
- 原脚本的少数拼写差异通过显式兼容映射处理，源脚本不改写。对白显示时长为浏览器阅读辅助。
- 第一关没有显式 `GameOver` 调用；「敌对任务 NPC 全部击败后完成」是 Rule 10 宿主适配规则，尚未从 EXE 证明。宿主记录推断与未支持 API。
- sn22 几何异常；武器 w6_5 在源目录中缺失，3 张 advancedninja 场景贴图也缺失，不用程序模型冒充原素材。
- 目前是浏览器单机，没有多人房间、网络同步或原协议兼容服务。

```sh

npm run check
```

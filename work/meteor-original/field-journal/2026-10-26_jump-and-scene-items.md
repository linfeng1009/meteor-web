# 原生动画场景位移与 Web 物理的衔接

日期：2026-10-26。范围：本地授权客户端，只读资源、Web 实现与验证。

用户报告跳跃后人物脱离镜头。只检查 fighter.root 会漏掉骨骼树顶层 dummy 的整体位移：原 BNC 的骨 b 从属于 d_base，BANIM 同时给 d_base 设置世界移动，Web 物理又独立让 root 上升。修复应对齐整棵蒙皮和挂点树与碰撞体，不能只让镜头追逐错位模型，也不能抹掉骨盆局部高度。恢复各角色自己的 BNC base pivot；P19 的非零 pivot 是避免硬编码零点的重要反例。

验证同时测真实模型投影、场景 base 与物理 root 距离、原挂点相对骨盆的向量、非就地原轨迹，以及自然落地。旧实现镜像 8 项失败，修复后 10 项通过。浏览器截图补充实际渲染，CPU 不代替设备体验。

机关交互另沿真实三角 → 原数值 → 原 PST → 原破碎姿态 → 原掉落实例推进；把效果身份绑定 RES type2/id1/model，而不是网格外观。可达检查须忽略物品自身碰撞，却保留其他墙体遮挡。新拾取只实现原肉包即时 +300 HP，范围、显式按钮、满血保留与不计时重生均明确记录为 Web 适配，不扩大到全物品语义。
